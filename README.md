# Second Volt (cos10026-kmcc)

Demo site for a second-hand electronics store. HTML and CSS only.

## Files

- `index.html` - home page
- `styles.css` - shared stylesheet

## Style rules

- Use the colour variables in `:root`.
- Write phone styles first, then wider screens with `min-width` media queries.
- Keep class names lowercase and hyphenated.
- Add new styles in their own block above the footer.
