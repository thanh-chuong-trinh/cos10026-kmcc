# Second Volt (cos10026-kmcc)

Demo site for a second-hand electronics store. HTML and CSS only.

## Files

- `index.html` - home page
- `jobs.html` - job listings
- `apply.html` - job application form
- `about.html` - about the team
- `styles.css` - shared stylesheet
- `images/` - logo, hero pattern, group photo and product photos (credits are listed at the bottom of `index.html`)

## Links

- Live site: https://thanh-chuong-trinh.github.io/cos10026-kmcc/
- Jira board: https://zinbattle3.atlassian.net/jira/software/projects/GROUP6/boards/2/backlog

## Style rules

- Use the colour variables in `:root`.
- Write phone styles first, then wider screens with `min-width` media queries.
- Keep class names lowercase and hyphenated.
- Add new styles in their own block above the footer.
